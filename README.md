# MyVault

个人 Markdown 学习知识库，覆盖 Java、后端、前端、Agent、算法和 Python。

## 阅读入口

- [学习知识库总览](index.md)
- [面试题与项目答辩](interview/index.md)
- [学习入口与沉淀流程](learning-plan.md)

## 内容结构

- `notes/`：知识原理、示例与源码学习笔记。
- `daily/`：学习日志。
- `interview/`：通用技术题集与项目答辩。
- `interview-plan/`：学习安排与练习记录。
- `pitfalls/`：问题排查与解决过程。
- `resources/`：学习资源。
- `templates/`：文档模板。

## 使用方式

从总索引开始阅读，或在 Obsidian 中打开本目录。文件之间使用标准 Markdown 相对链接。

项目答辩与学习记录中的未核实事项以正文标注为准，收录不代表实现、指标或知识掌握程度已得到验证。
