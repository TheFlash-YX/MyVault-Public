# 概述

- Python 里「除不尽往哪砍」有三种规矩：`//` 向 -∞（floor）、`int()` 向 0（truncate）、`round()` 就近偶数（银行家舍入）；**正数时三者趋同，负数才分家**

# 详细内容

## 三种方向对照（以 -3.5 为例）

```
        -4   -3   -2   -1    0    1    2    3
---------|----|----|----|----|----|----|----|----→
                  ↑ -3.5 在这里
       floor──┘  └──truncate
       (往 -∞)      (往 0)
```

| 表达式 | 语义 | `-3.5` 的结果 | `3.5` 的结果 |
|---|---|---|---|
| `a / b` | 真除法，**返回 float** | -1.5（`-3/2`） | 1.75 |
| `a // b` | floor，往 -∞ 砍 | **-2** | 1 |
| `int(x)` | truncate，往 0 砍小数 | **-3** | 3 |
| `round(x)` | 银行家舍入（.5 取偶） | -4（-3.5→-4，偶） | **2**（3.5→4 但 2.5→2）|
| `math.floor` / `math.ceil` | 明示 floor / 天花板 | -4 / -3 | 3 / 4 |

- `round` 的坑：四舍六入五成双——`round(2.5)=2`、`round(3.5)=4`，不是"五入"

## 为什么算法题常要求 int(a/b) 而不是 a//b

- LeetCode 计算器类题（如 227）规定 truncate toward zero（C/Java 语义）；Python `//` 在**负数且除不尽**时给出不同答案
- 负数从哪来：`-num` 压栈技巧让中间结果变负——`14-3/2`：栈 `[14, -3]`，`-3/2` 应得 -1（答案 13），`//` 得 -2（错成 12）
- 修法：`int(a / b)`——先算浮点真值，`int()` 砍向 0

## 大数精度与纯整数写法

- `int(a/b)` 走 float，超过 2⁵³ 丢精度；面试官较真时给纯整数版：
  - `a // b if a >= 0 else -((-a) // b)`（先按绝对值 floor，再贴回符号）

## 跨语言对照

- C / Java / Go 的整数 `/` **天生 truncate 向零**——计算器题在那边无此坑
- Python `//` 选 floor 是设计哲学：保证 `a == (a // b) * b + a % b` 恒成立，`%` 结果符号**随除数**（`-7 % 2 = 1`，C/Java 里是 -1）
