# 概述

面向对象开篇：类是对象的模板（图纸），对象是类的实例（实物）。构造方法负责对象的初始化，`this` 指向当前对象。`new` 一个对象时，JVM 在堆分配内存、赋默认值、执行构造方法、返回地址给栈上的引用。

# 详细内容

- **类 vs 对象**：类=饼干模具（抽象模板），对象=压出的饼干（具体实例）；一个类可 new 无数个独立对象。
- **类三大组成**：字段（对象"有什么"）、构造方法（对象"怎么造出来"）、方法（对象"能做什么"）。
- **构造方法四铁律**：
  - 名字必须与类名完全相同；
  - 没有返回类型（连 void 都不能写）；
  - 只能用 `new` 调用；
  - 作用是初始化对象（给字段赋初值）。
- **构造方法重载**：多个构造方法同名、参数不同，`new` 时按参数自动匹配。
- **默认构造**：一个都不写时编译器赠送空的无参构造；只要自己写了任何一个，赠送取消（此时 `new 类名()` 编译报错）。
- **`this` 两种用法**：
  - `this.字段`：指向当前对象字段，参数与字段同名时区分二者（不加 this 被参数就近覆盖）；
  - `this(...)`：在构造方法里调用本类另一个构造方法，**必须写在第一行**（实现初始化逻辑集中、避免重复代码）。
- **`new Person("小明",18)` 全过程**：①堆分配内存→②字段填默认值（name=null,age=0）→③执行构造方法初始化→④把对象地址返回给栈上引用变量。
- 引用是"遥控器"：栈上变量只存地址，对象本体在堆——呼应 [JVM 堆与栈](./heap-vs-stack.md)。
- **面试标准答法**：类是模板、对象是实例；构造方法与类同名无返回类型、new 调用、负责初始化，不写有默认无参、写了不再赠送；this.字段区分成员变量和参数，this() 在构造首行调本类其他构造；new 时先堆分配+默认值，再执行构造初始化，最后返回地址给引用。
