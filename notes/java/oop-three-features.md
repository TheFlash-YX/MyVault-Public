# 概述

面向对象三大特性。封装把字段私有化、暴露受控方法保证数据安全；继承让子类复用父类代码（Java 单继承）；多态是"父类引用指向子类对象、同一方法不同表现"，是开闭原则与框架设计的基石。多态三个必要条件是高频考点。

# 详细内容

- **封装**：
  - 字段设 `private`，提供 `public` getter/setter，在 setter 里加校验（如 `setAge` 拦截负数）；
  - 解决"数据被乱改"问题；类比取款机——钱锁里面，只能插卡输密码取。
- **继承**：
  - `class Dog extends Animal`，子类自动拥有父类字段和方法；
  - `super` 指向父类：`super(...)` 调父类构造（须第一行）、`super.方法()` 调父类方法；
  - 解决代码重复；**Java 只支持单继承**（多能力用接口 implements）。
- **多态**：
  - 体现：`Animal a = new Dog(); a.speak();` 运行时执行 Dog 的 speak；
  - 规则：**编译看左（父类有这方法才能编过）、运行看右（实际对象决定执行谁的版本）**；
  - **三个必要条件**（必背）：① 继承 ② 重写（@Override）③ 父类引用指向子类对象。
- **`@Override`**：注解，声明重写父类方法，方法名/参数必须完全相同，写错编译器提醒。
- **多态的价值**：程序面向父类/接口编程，新增子类不改原代码即可扩展（开闭原则）。
- 三特性对照：封装=private+getter/setter 解决数据被乱改；继承=extends+super 解决代码重复；多态=继承+重写+向上转型 解决程序僵硬难扩展。
- **面试标准答法**：封装私有化字段+公开方法受控访问保证安全；继承 extends 复用、单继承、super 引用父类；多态是同一调用不同对象不同行为，需继承+重写+父类引用指向子类对象三条件，使程序面向父类/接口编程、易于扩展。
