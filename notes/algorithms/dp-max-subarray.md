# 概述

- 连续子数组类 DP 的统一框架：状态必须**以 i 结尾**、答案全表扫最大；乘积版引入符号维度后维护 max/min 双状态

# 详细内容

## 两种状态口径（本质区别）

- 「以 i 结尾」（53/152/718）：`dp[i]` 强制包含 `nums[i]`——连续结构递推的前提（否则没有「从 i-1 延伸过来」的资格）；**答案 = max(所有 dp[i])**，因为最优子数组可在任意位置结束
- 「考虑到 i 为止」（198 打家劫舍）：`dp[i]` 可不含第 i 间；**答案 = dp[n-1]** 直接取最后一位
- 口径决定答案获取方式——状态定义的措辞就是算法的一半

## 53 最大子数组和（Kadane）

- `dp[i] = max(dp[i-1] + nums[i], nums[i])`：前面的积累是正资产则延伸 / 负资产则甩掉重新开段
- 等价变形：`max(dp[i-1], 0) + nums[i]`
- cur/ans 滚动变量 O(1) 空间；ans 全程维护（不是 dp[n-1]）
- 样例轨迹 `[-2,1,-3,4,-1,2,1,-5,4]`：dp 依次 `-2 1 -2 4 3 5 6 1 5`，ans 最终 6

## 152 乘积最大子数组

- 加法里更大积累永远是资产；乘法里**符号会翻脸**：当前 `x < 0` 时，旧 min × x 反超旧 max × x（`[-2,3,-4]`：扫到 -4 时最优 24 = 旧 min(-6) × -4）
- 双状态交叉递推：`dp0, dp1 = max(dp0*x, dp1*x, x), min(dp0*x, dp1*x, x)`
- **高频 bug：递推缺交叉项**——只写 `max(dp0*x, x)` 在 `[-2,3,-4]` 会返回 -4 而非 24；旧 min 必须参与新 max 的竞争（反之亦然）
- 0 的处理：`max(…×0, …×0, 0) = 0`，重启项 x 永远在候选里，与 53 同构，无需 if 分支
- 初始化 `dp0 = dp1 = 1`（空乘积），首轮自动推出 `dp0 = dp1 = x`，免 base case
- 元组赋值一行替代 temp 保旧值；先 temp 后两条赋值的写法也对（temp=旧 dp0，dp1 行用 dp1 与 temp，均旧值）
- 必须维护全局 `ans = max(ans, cur_max)`；`cur_max` 只表示“以当前位置结尾”的最优值，直接返回最后一个 `cur_max` 会漏掉更早结束的最优子数组，例如 `[2,3,-2,4]`。
- 右侧表达式会先整体求值，因此 `cur_min, cur_max = new_min, new_max` 不会让更新后的值污染另一状态。

## 718 最长重复子数组（二维推广）

- `dp[i][j]` = **以 nums1[i-1]、nums2[j-1] 结尾**的公共子数组长度——「以 i 结尾」的二维形态；答案仍是全表扫
- 转移：相等 → `dp[i-1][j-1] + 1`（沿对角线延长）；不等 → **0**（链条在此清零重启）
- **为什么不能像 1143 LCS 取 `max(dp[i-1][j], dp[i][j-1])`**：这两个动作的含义是「跳过 nums1/nums2 的一个元素」——子序列允许空隙（跳过合法），子数组必须连续（跳过即犯罪）
- 为什么不能用「考虑到 i、j 为止」口径：相等时新匹配能否接上，取决于旧公共子数组是否**恰好结束在 (i-2, j-2)**；矩形区域最大值不记录位置，信息丢失、递推写不出来
- 答案必须全表扫：样例 `[1,2,3,2,1]` vs `[3,2,1,4,7]` 中最优 `[3,2,1]` 结束在 dp[3][3]=3，而 dp[5][5]=0（末对元素不等）——取 dp[m][n] 会返回 0
- 建表 `(m+1)×(n+1)` 外圈 0 = 空数组，免 base case；不等分支 `dp[i][j]=0` 可省（每格只写一次，建表已是 0）
- 一行流全表扫：`max(map(max, f))`——`map(max, f)` 逐行求行最大，外层 max 取全表
- enumerate 变体：`for i, x in enumerate(nums1)` 配 `f[i+1][j+1]`，写入位置错开一位，等效于 padding 一圈
- 718 的二维表若开成 `(n+1)×(m+1)`，就要统一把比较结果写到 `dp[i+1][j+1]`，从 `dp[i][j]` 延伸；不要用 `dp[i-1][j-1]` 的负下标去“碰巧”访问边界。
- “前 i 个元素中的最优值”和“以第 i 个元素结尾的最优值”是两种不同状态；718 必须使用后者，才能在不相等时清零并保证连续性。
