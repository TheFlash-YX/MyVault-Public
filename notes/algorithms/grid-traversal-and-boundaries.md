# 详细内容

## 200/695：整座岛屿的 DFS

- 四个方向为上下左右，不包含对角。一次完整 DFS 会沿邻接陆地递归，访问整座岛，不只起点的四个邻居。
- 入口先检查坐标是否越界，再访问格子判断是否为水；当前陆地先标记为水，再搜索四个方向。
- 200 使用字符串 1、0，每发现尚未访问的陆地就启动一次 DFS，岛屿数加一；加一放在本次 DFS 前或后均可。
- 695 使用整数 1、0，DFS 返回本次调用及递归中新访问的陆地数量。越界或水返回 0，新陆地返回 1 加四个方向的结果，外层取最大值。
- 标记永久保留，不是回溯，不要在返回时恢复陆地；两题都会修改原网格。
- 总时间 O(mn)，不是外层扫描乘以每次 DFS 的面积；所有 DFS 合计每个陆地只标记一次。递归栈最坏 O(mn)，长链可能触及 Python 递归深度限制。

## 两次真实错误

- 200 首稿用 `0<=i<m-1 and 0<=j<n-1` 统一控制四个递归，导致最后一行或列无法继续搜索；单行 `[['1','1']]` 会被计成两座岛。
- 当前 i>=0 并不保证 i-1>=0；Python 的 -1 会访问末行，可能错误连接不相邻格子。每个递归入口应独立检查完整坐标。
- `not grid[i][j]` 不能检测越界，求值时已经访问数组；字符串 '0' 和 '1' 也都为真。
- 695 首稿把标记写成 `grid[r][c]==0`，只是比较，没有赋值；相邻陆地互相递归，可表现为超时或递归深度错误。修复为单等号赋值后，用户报告通过。

## 54：四边界收缩

- top、bottom、left、right 表示尚未遍历的闭矩形区域；方向依次为右、下、左、上。
- 走完上边后 top+=1，右边后 right-=1，下边后 bottom-=1，左边后 left+=1。
- 每收缩一条边，就检查对应上下或左右边界是否交错；只剩单行或单列时应及时结束，避免重复输出。
- 后一个方向使用更新后的边界，因此角落不会重复访问；向左或向上使用步长 -1，并注意 range 右端不包含。
- 时间 O(mn)，不计输出的辅助空间 O(1)，不修改矩阵。

## 54：方向数组与 None 标记

- 方向数组按 [(0,1),(1,0),(0,-1),(-1,0)] 排列；di 表示当前方向，初始从 (0,0) 向右。
- 每轮收集当前元素，将其改为 None，然后检查当前方向的下一格；越界或已访问时 di=(di+1)%4，最后按新方向移动。
- 先判断越界再读取下一格，依靠 or 短路防止非法访问；输入原本为整数，None 可以作为已访问标记。
- 固定执行 rows*cols 次；最后一次收集后即使坐标继续移动，也不会再访问矩阵，所以不影响结果。
- 尚有未访问元素时，顺时针沿未访问区域边缘行走，遇阻右转一次即可继续；循环计数负责最后一格后的结束。
- 时间 O(mn)，不计输出的辅助空间 O(1)，会把原矩阵改成 None；此差异应与四边界法区分。

## 240：从右上角搜索

- 行、列分别非递减，不保证下一行首元素大于上一行末元素，不能把全矩阵直接看成有序一维数组。
- 从 r=0、c=cols-1 出发；相等返回 True，目标大于当前值则 r+=1，否则 c-=1。
- 当前值过小，则当前行剩余元素都不够大；过大，则当前列剩余元素都过大。每步排除一行或一列，不是任意排除整个左上角。
- 循环条件 r<rows 且 c>=0，退出返回 False。时间 O(rows+cols)，空间 O(1)，不修改输入。

## 48：顺时针旋转方阵

- 坐标 (r,c) 顺时针旋转后为 (c,n-1-r)，可拆为主对角线转置 (r,c)→(c,r)，再逐行左右反转。
- 转置只遍历 c 从 r+1 到 n-1；若同时访问上下三角，同一对会交换两次，恢复原样。
- 用户首版遍历全矩阵但只在 c>r 时交换，逻辑正确；后来缩小循环范围并去掉 return matrix，遵守原地修改、返回 None 的约定。
- 时间 O(n²)，额外空间 O(1)；用户于 2026-10-09 报告优化版通过，未另行本地测试。
