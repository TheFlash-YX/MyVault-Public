# 概述

- 二叉树层序遍历的核心不变量：每轮 `while queue` 开始时，队列中刚好是当前层所有节点。
- `level_size = len(queue)` 固定本层循环次数；本层中新加入的孩子节点不会被本层消费，而是自然留到下一轮。

# 详细内容

## 102 层序遍历

- 使用队列保存待访问节点，根节点先入队。
- 每层开始记录当前队列长度，只弹出这一批节点。
- 弹出节点时收集节点值，并把非空左右孩子入队。
- 时间复杂度 `O(n)`：每个节点入队、出队一次。
- 空间复杂度 `O(w)`：队列最多保存树的最大宽度，最坏 `O(n)`。

## 103 锯齿形层序遍历

- 队列仍然按普通 BFS 维护树的层结构，左右孩子照常从左到右入队。
- 用 `flag` 控制当前层答案方向：正向层直接收集，反向层可以对当前层结果反转，或用 `deque.appendleft` 构造。
- 不要为了“从右往左输出”修改孩子入队顺序；入队顺序负责遍历结构，输出容器负责展示方向。

## 199 二叉树右视图

- 仍然使用 102 的分层 BFS 框架，每层开始先固定 `level_size`。
- 当前层 `for i in range(level_size)` 中，`i == level_size - 1` 的节点就是这一层从右侧能看到的节点。
- 不建议用遍历过程中的 `queue[-1]` 直接判断当前层最右节点，因为当前层消费时会不断把下一层节点加入队尾。
- 判断代码写在孩子入队前后都不影响正确性，只要判断条件依赖的是进入本层前固定的 `level_size`。

## 662 二叉树最大宽度

- 普通 `len(queue)` 只能得到当前层真实存在的节点数，不能表示包含中间空位的满二叉树宽度。
- 队列中保存 `(node, idx)`，`idx` 是节点在满二叉树中的位置编号。
- 若从 0 开始编号，左孩子是 `2 * idx + 1`，右孩子是 `2 * idx + 2`。
- 每层开始时，队列刚好保存当前层节点，宽度是 `queue[-1][1] - queue[0][1] + 1`。
- 必须用 `level_size` 一次处理完整一层；如果每轮只弹一个节点，队列会混入当前层剩余节点和下一层节点，宽度计算失去层语义。
- Python 整数不会溢出，但面试中可以主动说明每层用首个编号做归一化，避免编号随深度指数增长。

## 复杂度账

- 某一层反转代价是该层节点数 `k`。
- 所有层的节点数加起来等于整棵树节点数 `n`，所以所有反转总代价仍是 `O(n)`。
- BFS 本身也是 `O(n)`，因此 103 使用逐层反转时整体仍是 `O(n)`。
