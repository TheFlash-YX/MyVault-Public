# 概述

- 摩尔投票法：O(n) 时间、O(1) 空间求"出现**超过 n/2**"的多数元素（169 保证存在时可省验证）

# 详细内容

## 核心思想：一换一对拼

- 每个非多数元素最多拼掉一个多数元素；非多数元素总共 `< n/2` 个，拼不完 `> n/2` 个多数元素 → 多数元素必然存活
- **相邻物理配对不可行**：`[2,2,1,1,1]` 中相同对不消、消掉后打洞（置 -inf）导致下一轮配对错位 → 正确实现是"流动候选 + 计数器"

## 实现（流动候选）

```python
def majorityElement(nums):
    candidate, count = None, 0
    for x in nums:
        if count == 0:          # 前阵营全军覆没，换人当候选
            candidate = x
        count += 1 if x == candidate else -1   # 同党 +1，异党对拼 -1
    return candidate
```

## 实现易错：两个决策不能揉成一个条件

- 错误写法 `if count == 0 and candidate == x: count += 1 else: count -= 1`：count==0 时来了**异党** x，本该换候选却走了扣票 → count 一路变负、candidate 永不更新，`[2,2,1,1,1]` 返回 2
- 报警信号：count 出现**负数**（票数不可能为负，值域直觉即 debug 工具）
- 两个决策必须独立：① 换候选只看 `count == 0`（不看 x 是谁——归零即战场清空，谁来谁开新营）；② 计数增减只看是否同党
- 正确写法两段式 `if count==0: candidate=x` + `if candidate==x: count+=1 else: count-=1`，与三元 `count += 1 if x == candidate else -1` 完全等价（三元是表达式，else 后跟**值**不跟语句）

## 陷阱：count 不是真实票数

- 结束时的 `count` 是"换过多任候选后残留的净值"，**不等于 candidate 的真实出现次数**
- 反例 `[1,2,3]`：结束时 candidate=3、count=1 > 0，但 3 只出现 1 次，并非多数元素
- 所以**多数性不保证时**（如 229 求超过 1/3 的元素），必须第二遍遍历真实计数验证
- 完整形态 = **第一遍找候选（投票）+ 第二遍验证（计数）**；169 因题目保证多数存在才可省略第二遍

## 229：超过 n/3 的多数元素

- 最多有两个答案：若三个不同值的出现次数都严格超过 n/3，次数之和将超过 n。
- 第一轮维护两个候选与各自的剩余票数。先匹配已有有效候选并加票；否则占用票数为 0 的空位；若两个候选都不同且都有票，两个票数各减一。
- 最后一种操作相当于抵消三个不同元素。超过 n/3 的真实多数元素不会因成组三个的抵消而全部消失；第一轮只能保留可能的答案。
- 判断候选相等时应同时检查其票数大于 0；初始候选值可能与输入相同，但零票位置还不是有效候选。
- 第二轮重新遍历原数组，统计候选的真实出现次数，仅保留 `count > len(nums)//3` 的元素。`[1,2,3,4]` 第一轮可能留有候选，真实次数却都不超过 1，因此答案为空。
- 两次遍历为 O(n) 时间；固定两个候选及其计数为 O(1) 额外空间。

## 双候选的字典表示与计数法

- 用户先用最多两个键的字典表示“候选值 → 剩余票数”，与四个变量表示法的投票逻辑相同，字典本身仍是 O(1) 额外空间。
- `for key, val in candidate` 遍历字典只得到键；要同时获取键值，应使用 `.items()`。如果第三种数字的分支未执行，错误可能先在最后的验证循环中暴露。
- 不能边遍历 `candidate.items()` 边删除键，会报 `RuntimeError: dictionary changed size during iteration`；遍历 `list(candidate)` 的键快照，再对原字典减票并删除归零键。
- 归零候选必须释放位置；否则后续新值无法进入候选表。
- 投票字典中的值不是实际出现次数。可针对最终候选重新扫描 nums，再比较真实次数；本次用户请求后阅读了完整参考实现，未把它记作独立手写通过。
- 另一种官方题解直接用字典统计每个数字的真实次数，再筛选 `> n//3` 的键；它无需额外验证遍，但字典最坏含 n 个不同键，空间 O(n)，时间 O(n)。
- 官方双候选实现同样做“筛候选 + 真实计数”两遍；`len(nums)/3` 比较可写为 `len(nums)//3`，对整数次数的严格大于判断等价。
