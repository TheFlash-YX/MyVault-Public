# 详细内容

## 72：编辑距离

- dp[i][j] 为 word1 前 i 个字符变成 word2 前 j 个字符的最少操作次数。
- dp[i][0]=i，dp[0][j]=j，分别对应删除到空串和从空串插入。表格大小 (m+1)×(n+1)。
- 末尾字符相等时取左上 dp[i-1][j-1]；不等时取删除 dp[i-1][j]+1、插入 dp[i][j-1]+1、替换 dp[i-1][j-1]+1 的最小值。
- 插入分支是先转成目标的前 j-1 个字符，再补最后一位；删除分支是去掉原串最后一位后处理剩余部分。
- 实际错误：只考虑替换漏掉插入和删除；省略边界初始化会使 ab→空串错误返回 0。
- 实际错误：返回全表最大值。ab→ab 的答案是终点 0，但边界存在 2；必须返回 dp[m][n]。

## 1143：最长公共子序列

- dp[i][j] 为两个前缀的最长公共子序列长度。子序列保留相对顺序，不要求连续；边界整行整列为 0。
- 相等时 dp[i][j]=dp[i-1][j-1]+1；不等时 max(dp[i-1][j],dp[i][j-1])，分别跳过一个末尾字符。
- 不等不能清零：之前的公共子序列仍有效。718 则要求连续，其状态是以两端点结尾，遇不等清零并全表取最大；不能混用定义。

## 一维压缩：覆盖旧值前先保存

从左往右更新时，dp[j] 尚为上一行的上方，dp[j-1] 已为当前行左侧；左上方需独立保存。

```python
temp = dp[j]  # 旧上方，下一列的左上方
# 根据 dp[j]、dp[j-1]、prev 更新 dp[j]
prev = temp
```

- 72 初始 dp=list(range(n+1))；每行进入内层循环前 prev=dp[0]，再 dp[0]=i。
- 1143 初始全 0，dp[0] 始终为 0，每行 prev=0 即可。
- 字符相等或不等，都必须保存旧 dp[j] 并在结束时推进 prev。1143 也需要 temp 或等价的旧值保存，教学中只展示转移片段不代表可省略。
- 实际错误：内层从 1 开始却把边界初始化放在 if j==0 内，永远不会执行。
- 实际错误：prev=dp[j-1] 会读到已更新的左侧，而不是旧左上方。
- 两题时间 O(mn)，空间由 O(mn) 降至 O(n)；选择较短字符串作列可降至 O(min(m,n))。仅讨论了后一优化，没有另外声称用户提交过交换字符串版本。
