# 概述

- `cur` 保存当前层已解码的字符串，`k` 累积下一对括号的重复次数。
- 栈保存暂停处理的外层状态 `(外层已有字符串, 重复次数)`，闭合括号时恢复。

# 详细内容

## 四种字符分别处理

- 数字：`k = k * 10 + int(c)`，支持多位数；也可先收集数字字符再整体转换。
- `[`：压入 `(cur, k)`，然后令 `cur = ''`、`k = 0`，开始处理内层。
- `]`：弹出 `(prestr, repeat)`，令 `cur = prestr + cur * repeat`，合回外层。
- 字母：追加到当前层 `cur`。扫描结束返回 `cur`。
- 四种情况用互斥分支组织。不能无条件执行 `cur += c` 和 `int(c)`，否则括号、数字会混入正文，非数字转换还会报错。

## 嵌套为什么需要保存外层字符串

- 对 `3[a2[c]]`，直接按括号下标截取原文会拿到未解码的 `a2[c]`，不能直接重复它。
- 外层 `[` 保存 `('', 3)`；内层 `[` 保存 `('a', 2)`。
- 内层闭合得到 `'a' + 2 * 'c' = 'acc'`；外层闭合得到 `'' + 3 * 'acc' = 'accaccacc'`。
- 每次遇到 `]` 的结果仍可能参与外层重复，不能立即作为最终答案独立追加。
- 合法输入下，每个次数在遇到对应 `[` 时保存并将 `k` 清零；闭合时使用弹出的 `repeat`，无需再依赖全局 `k`。

## 复杂度注意

- 扫描输入字符只需一遍，但字符串重复和拼接会创建内容，不能把整体时间简单记为输入长度的 `O(n)`。
- 输出长度 L 可能远大于输入长度，生成输出至少需要 `Ω(L)` 时间；这种直接拼接写法在嵌套时还可能反复复制中间结果。
- 栈中保存字符串前缀，因此空间也不能只按括号深度计算；需要计入保存的前缀、当前字符串与拼接产生的临时内容。
