# 详细内容

## 121：最多一次交易

- 此前最低价格用于买入，不是卖出；不能直接全局最大值减最小值，因为最大值可能出现在最小值之前。
- dp[i] 表示截至第 i 天的最大利润，dp[0]=0。维护截至当前的 min_price，转移为 dp[i]=max(dp[i-1],prices[i]-min_price)。同日买卖贡献零，不影响结果。
- dp 单调不减，返回 dp[-1] 即可，用户首版 max(dp) 正确但多做一次扫描。
- 每轮只依赖上一天利润，可压缩为一个利润变量和 min_price。时间 O(n)，空间由 O(n) 降到 O(1)。

## 122：多次交易的持股双状态

- dp[i][0] 为第 i 天结束不持股的最大累计收益；dp[i][1] 为持股时已扣买入成本、不计股票市值的最大累计收益。
- 初始化为 0、-prices[0]；不持股取 max(dp[i-1][0],dp[i-1][1]+prices[i])，持股取 max(dp[i-1][1],dp[i-1][0]-prices[i])。最终返回不持股状态。
- 多次交易买入时必须保留之前的已实现利润。例如 [1,5,3,6] 先赚 4，再以 3 买入，持股收益为 1，不是 -3。
- 数组首版内层 for j in range(2) 未使用 j，每轮重复计算两个状态；删去即可，重复两次只影响常数，时间仍 O(n)。
- 压缩为 cash、hold，采用同时赋值让两个新值都从旧状态计算：`cash, hold = max(cash, hold+p), max(hold, cash-p)`。时间 O(n)，空间由 O(n) 降至 O(1)。
- 本题先更新 cash 再更新 hold 也成立：max(hold_old,max(cash_old,hold_old+p)-p)=max(hold_old,cash_old-p)，多出的候选只是旧 hold。不能不经推导推广到有冷冻期等其他约束。

## 300：以当前位置结尾的 DP

- dp[i] 是必须以 nums[i] 结尾的最长严格递增子序列长度；初始化全部为 1。
- 枚举 j<i，仅在 nums[j]<nums[i] 时，用 dp[j]+1 更新 dp[i]。
- 答案取 max(dp)，不是 dp[-1]；最优序列不一定在末尾结束。时间 O(n²)，空间 O(n)。

## 300：最小尾值与 lower_bound

- tails[k] 表示已扫描部分中，长度 k+1 的递增子序列的最小末尾值；末尾越小，越容易接入后续数字。
- tails 严格递增，但不同长度的最优尾值可能来自不同路径，整个 tails 不保证是原数组的一条真实子序列。
- 对 num 找第一个 >=num 的位置：存在则替换，否则追加。重复值只替换，不延长；[2,2,2] 的答案为 1。
- 闭区间二分：tails[mid]>=target 时 right=mid-1，否则 left=mid+1，最终返回 left。不是查找等于 target+1 的位置。
- 若 tails 为空或 num>tails[-1]，直接追加；否则二分结果必然在数组内，不必再判断是否等于长度。
- 时间 O(n log n)，空间 O(n)；直接追加分支使严格递增输入只需 O(n) 时间。
