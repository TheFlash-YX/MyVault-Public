# 概述

- 46、47 枚举所有排列；31 只求当前排列在字典序中的下一个，使用原地调整。
- 46 最终代码经审阅正确；47 用户报告 LeetCode 通过；31 最终代码经审阅正确，未报告平台提交。

# 详细内容

## 46：所有元素互不相同

- `path` 是正在构造的排列，`used[i]` 表示下标 i 已在当前路径中；每层都从下标 0 开始检查所有元素。
- `used[i]` 为 True 时跳过；选择后追加 path、标记 used、递归，再弹出并恢复 used。
- `len(path)==len(nums)` 时保存 `path[:]` 并返回；直接保存 path 会让后续回溯修改已存结果。
- 最初误用 `idx` 控制下一层扫描范围，导致只能向后选，漏掉 `[2,1]`；曾缺少 `used[i]` 检查，会重复使用同一下标。
- `n!` 个结果，每个长度 n，时间 O(n·n!)；递归路径与 used 为 O(n)，结果空间另计。

## 47：输入可有重复值，输出不能重复

- 先排序，让相同值相邻；仍用 `used[i]` 阻止同一路径重复使用下标。
- 若 `i>0`、`nums[i]==nums[i-1]`、`not used[i-1]`，则跳过当前 i：此前同值已在当前层开过分支。
- 若此前同值下标已在当前路径中，`used[i-1]` 为 True，则可以选择当前相同值，例如 `[1,1,2]` 允许两个不同下标的 1 同时入路径。
- 根层选第二个 1 会复制根层选第一个 1 的整批结果，所以跳过；深入第一个 1 的分支后再选第二个 1 则合法。
- 排序会修改 nums；最坏所有值不同，时间 O(n·n!)，递归与 used O(n) 空间，另有 Python 排序的临时空间及输出空间。

## 31：紧邻的下一个排列

- 从右往左找首个 `nums[i]<nums[i+1]`。其右侧原本非递增，已是该后缀能组成的最大顺序；只有改变更靠左的位置才能使整体变大。
- 从右往左找首个 `>nums[i]` 的值，它是后缀里最小的更大值，与 nums[i] 交换。
- 交换后把 i 右侧反转为非递减顺序，让整体只增加到下一个排列。
- 若找不到 i，整个数组已经非递增、是最大排列，直接原地反转为最小排列。
- `[1,3,2]`：i=0，换 1 与 2 得 `[2,3,1]`，再反转后缀得 `[2,1,3]`。
- 最初误以为只调整非递增后缀即可变大，或直接与 i+1 交换；后者可能跳过紧邻答案。
- `list.reverse()` 原地修改且返回 None；`nums = nums[:i+1] + nums[i+1:][::-1]` 只重新绑定局部变量，不满足原地修改要求。
- 用户最终用 `nums[i+1:] = nums[i+1:][::-1]` 修改原列表；时间 O(n)，切片临时空间 O(n)。若严格限制 O(1) 额外空间，可用左右指针交换反转后缀；本次未独立实现这一优化。
- `nums[i+1::-1]` 从 i+1 向左取到下标 0，反转的是前缀方向，不是后缀。
