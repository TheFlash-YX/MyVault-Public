- 子集与组合都不区分选择顺序；通过 start 保持所选下标不向前走。是否允许复用当前位置，决定下一层传 i 还是 i+1。

# 详细内容

## 78：元素互不相同

- 每进入递归函数就保存 `path[:]`，因此初始空路径对应空集 `[[]]` 的一个成员。
- 从 `start` 到数组末尾逐个选 i；追加 nums[i]、递归传 i+1、返回后 pop。
- 不需要 used 数组：下标单调向后，已经选过的下标不会再次进入候选范围。
- n 个元素各有选或不选两种可能，结果数为 `2^n`；包含复制输出，时间 O(n·2^n)，递归路径 O(n) 空间，结果空间另计。

## 90：输入可有重复值，结果去重

- 先排序让相同数值相邻，仍然在每个递归入口保存当前 path。
- 同一层循环中，如果 `i>start and nums[i]==nums[i-1]`，跳过后一个相同值；本层已从前一个同值探索过等价分支。
- 若当前路径已经选了前一个相同值，下一层的 start 恰是第二个同值的下标，此时 `i==start`，允许选它，形成 `[2,2]`。
- 对排序后的 `[1,2,2]`：根层从第二个 2 开始会重复从第一个 2 开始的结果；第一个 2 入路径后，第二个 2 可继续入路径。
- 判断条件先写 `i>start` 再读 `nums[i-1]`；若反过来，i=0 时 Python 会读 nums[-1]，虽然最终不误剪，但语义不清晰。
- 排序会修改输入。最坏无重复值时，时间 O(n·2^n)，递归路径 O(n) 空间，另计排序临时空间和结果空间。

## 与排列 II 的去重条件比较

- 子集使用 start 限制只能向后选；是否为同一层，由 `i>start` 判断。
- 排列每层扫描所有下标，使用 used 记录当前路径；是否为同一层的重复开枝，由 `not used[i-1]` 判断。
- 两者都允许同一路径使用不同下标的相同数值，跳过的是同层的等价分支。

## 39 与 40：剩余目标值和递归起点

| 题目 | 输入与使用次数 | 下一层起点 | 收集答案 |
|---|---|---|---|
| 78/90 子集 | 每个位置至多一次 | i+1 | 每个递归入口 |
| 39 组合总和 | 数值互不相同，每个数可重复使用 | i | 剩余 target 为 0 |
| 40 组合总和 II | 输入可有重复值，每个位置至多一次 | i+1 | 剩余 target 为 0 |

- 39/40 的 target 表示还差多少，每选一个数就递归传 `target-candidates[i]`；为 0 时保存 `path[:]` 并返回。
- 候选均为正整数，所以剩余 target 小于 0 后不能再恢复，直接返回。
- 未排序时，当前候选大于 target 只能跳过当前数，不能结束整层循环；排序后后续数只会更大，可以 break。
- 已在递归前用 `candidates[i]>target` 剪枝时，不会产生负 target；入口的负数判断可以保留，也可以省略。

## 40 的真实错误与去重例子

- 首稿判断 `i>0 and used[i] and candidates[i]==candidates[i-1]`。由于下一层从 i+1 开始，当前候选尚未使用，used[i] 为 False，这个条件无法去重。
- 正确条件是 `i>start and candidates[i]==candidates[i-1]`，满足时 continue；下标只向后走，不需要 used。
- 去重不能用 break：例如 `[1,1,2]`、target=2，根层跳过第二个 1 后还应继续尝试 2，否则漏掉 `[2]`。
- `[10,1,2,7,6,1,5]` 排序得到 `[1,1,2,5,6,7,10]`。根层第二个 1 满足 i>start，应跳过；选了第一个 1 后进入下一层，第二个 1 的 i==start，可以继续选，保留 `[1,1,6]`。
- 已选 `[1,1,2]` 时剩余目标为 4，下个候选 5 超出目标，直接 break；根层遇到 10>8 同样结束。
- target=8 的结果为 `[1,1,6]`、`[1,2,5]`、`[1,7]`、`[2,6]`，每种组合只生成一次。

## 组合总和的复杂度口径

- 39 设 n 为候选数量、h 为 `target//min(candidates)`。递归路径深度 O(h)，未排序版本还可能多进入一层负目标状态；总时间取决于搜索规模，不能把每次递归的循环当作整体线性。按每个状态最多 n 个分支，`O(n^(h+1)+R*h)` 是 n>=2 时的宽松上界，R 为答案个数。
- 40 的路径深度 O(n)。包含循环扫描和复制答案，`O(n*2^n)` 是安全的最坏上界，排序另需 O(n log n)；剪枝可减少实际搜索。
- 40 的递归与路径空间 O(n)，Python 排序临时空间也最坏 O(n)；保存结果的空间另计。
