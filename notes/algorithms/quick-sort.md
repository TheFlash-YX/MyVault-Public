# 概述

- 快排 = 分治：**分**（partition 一趟把数组分成 `<=pivot | pivot | >=pivot`）+ **治**（递归重复分）+ **合（无）**；一趟划分只确定基准的最终位置，两侧内部尚未排好序。
- 与归并对举：归并「先治后合」（对半切很廉价，merge 才是主力）；快排「先分后治」（分即就地排序，无需合）
- 随机选 pivot，期望 O(n log n)、最坏 O(n²)、**不稳定**；空间 = 递归栈平均 O(log n)

# 详细内容

## 挖坑法（初学直观）

- pivot 值拎在手里，原位置成「坑」；j 找小填左坑→j 成新坑，i 找大填右坑→i 成新坑，坑接力传递，**i==j 相遇处放回 pivot**
- 内层比较用 `>=` / `<=`：跳过相等元素，否则全相等数组指针卡死死循环
- 短板：全相等数组 pivot 归到**端点**，每趟只归位 1 个 → 退化 O(n²)

## 双向交换法（灵神版，912 手写）

- 循环不变量 `[ pivot | <=pivot | 尚未遍历 | >=pivot ]`：i 跳过 `<pivot` 停在第一个 `>=pivot`，j 跳过 `>pivot` 停在第一个 `<=pivot`，两者交换后 **i+=1 j-=1 强制推进**
- 用严格 `<` `>` 也不死循环：靠「交换 + 强制推进」让指针动，而非跳过相等
- **结束与 `nums[j]` 交换而非 `nums[i]`**（面试常问，三个理由）：
  1. i 可能走到 `right+1` 越界，无法交换
  2. `nums[i]` 停在 `>pivot` 时换过去会把大于 pivot 的数放最左，破坏划分
  3. j 停在 `<=pivot`，即使 j==left 也是**自身交换，无害**
- **全相等数组：pivot 归中 → O(n log n)**（实验：8 个 3，交换法归位下标 4、挖坑法 0）——这就是 LeetCode 912 里防止 TLE 的关键
- 可选优化：递归前扫一遍子区间，已升序直接返回（有序输入整树剪枝）

## 工程细节与面试追问

- 随机 pivot 可降低持续遇到极端划分的概率，但最坏复杂度仍为 O(n²)；三数取中是选基准的启发式方法，不保证随机算法的期望界。
- **partition 单独拆出来可复用 Quickselect（TOP K，平均 O(n)）**：partition 返回 pivot 落点 p，与 target 比较后只递归一边
- 面试心法：能拆出 partition + 说清自己那版在全相等数组上的行为，就从「背代码」到「真懂」
- 相关：[相向双指针](./two-pointers.md)——双向交换 partition 是相向双指针的典型应用

## 215：只保留目标所在的一侧

- 第 k 大在升序数组中的目标下标是 `target=n-k`，重复值也参与排名；用户最初误写成 n-2，它只适用于 k=2。
- 维护当前闭区间 left、right，每轮仅调用一次 partition(nums,left,right)。目标下标始终不变。
- 返回位置 p==target 时返回 nums[p]；p>target 时令 right=p-1；p<target 时令 left=p+1。
- 用户首稿每轮重新划分整个数组，并在分支内再划分一次，随后覆盖结果；应只更新边界，让下一轮处理缩小的区间。
- target 是目标排名位置，不能直接作为新的搜索端点：被保留一侧内部没有排好序，不能跳过可能包含答案的元素。
- 随机快速选择期望时间 O(n)，最坏 O(n²)；用户采用迭代外层与原地划分，辅助空间 O(1)，会改变输入顺序。

## 本次 partition 的修正过程

- 随机函数是 `random.randint(left,right)`，不是 randomint；随机元素换到当前区间的 left，不是固定下标 0。
- 保存 pivot 值后，令 l=left+1、r=right；比较对象是 pivot，不是目标下标 target。
- 外层允许 l<=r；两次内层扫描都先检查 l<=r，再访问元素，避免越界。
- 左指针跳过 `<pivot`，右指针跳过 `>pivot`；未交错时交换两端并同时推进，重复值也能结束。
- 用 continue 代替推进会原地死循环；把交换误缩进到循环外，同样可能卡住，或在扫描结束后访问越界的 l。
- 扫描改为 <= 和 >= 后虽然可以划分，但全相等时基准会落在端点；随机选基准无法改善全相等情形，严格比较配合交换推进能避免这种退化。
- 循环结束后交换 nums[left] 与 nums[r]，返回 r；最初随机下标 index 不再表示基准最终位置。
