# 概述

- 1、41 已手写并报告通过；128 最终代码经审阅正确。
- 字典保存值与下标的映射，集合只判断存在，原地哈希利用位置编码信息。

# 详细内容

## 1：两数之和——先查再存

- 遍历到 num 时，补数是 `target-num`；字典保存此前数字到下标的映射。
- 先查补数，若存在返回当前下标 i 与补数下标；否则存入 `elem[num]=i`。
- 先存再查会把同一个元素使用两次，例如 `[3,2,4]`、target=6，处理首个 3 时错误返回 `[0,0]`。
- `[3,3]` 正常：第二个 3 能找到此前存入的第一个 3。
- Python 易错点：`elem((num,i))` 是调用字典，会报不可调用；正确存储语法是下标赋值。
- 返回当前下标直接用 i，不用 elem[num]；该键可能尚不存在，即使存在也表示先前位置。
- 时间平均 O(n)，空间 O(n)；题目保证有解，可不额外处理无解返回。

## 41：缺失的第一个正数——原地哈希

- 长度为 n 时，如果 1～n 有缺失，答案就在其中；如果全出现，n 个位置已经占满，答案为 n+1。
- 只把 `[1,n]` 范围内的整数 x 放到下标 x-1；负数、0、大于 n 的数不需要自己的位置。
- 换入当前位置的数可能还需要归位，所以用 while，而不是只交换一次。

```python
while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
    j = nums[i] - 1
    nums[i], nums[j] = nums[j], nums[i]
```

- 先检查范围再访问目标下标；目标位置已有相同值时停止，避免 `[1,1]` 无限交换。
- 交换前先保存目标下标 j，再使用两个确定下标交换。
- 不使用 enumerate 取出的 num 控制 while：它是取出时的整数值，不会随 nums[i] 的交换自动更新。
- 例如 `[2,3,1]`：处理 i=0 时先变成 `[3,2,1]`，必须再读取新值 3，继续交换成 `[1,2,3]`。
- 归位后，首个 `nums[i]!=i+1` 对应的答案是 i+1；如果全部匹配，返回 n+1。
- 不能仅检查 `1<=nums[i]<=n`：`[1,1]` 都在范围内，但仍然缺少 2。
- 时间 O(n)：每次交换都会新增至少一个归位位置；已经归位的位置不会再被换走，所有 while 总交换次数不超过 n。
- 外层扫描与最后检查各 O(n)，额外空间 O(1)，会修改输入数组。

## 128：最长连续序列——集合去重，只从起点扩展

- 连续指数值相邻，不要求在原数组中相邻；重复元素不增加长度，空数组返回 0。
- `num_set=set(nums)` 同时完成去重与快速存在性查询。
- 无序列表成员查询 O(n)，不能直接二分；集合成员查询平均 O(1)。
- 当 `x-1 not in num_set` 时，x 才是一段连续序列的起点；否则跳过。
- 从起点不断查询 x+1，累加长度并更新最大值。
- 外层必须遍历 num_set，而不是 nums，避免相同起点多次触发完整扩展。
- 反例：很多个 1 后接 2～k，若外层遍历 nums，每个 1 都会重复扩展同一段；重复数与序列长度均为线性量级时退化成 O(n²)。
- 只遍历集合且只从起点扩展后，不同序列互不重叠，每个唯一数字至多在所属序列内处理一次；加上起点检查和建集合，平均总时间 O(n)，空间 O(n)。
- `x+=1` 仅重新绑定局部整数变量，不修改集合，不影响外层集合遍历。
- 可读性调整：把长度初始化放在起点判断之后，continue 后不必写 else，集合命名 num_set 比 union 更清晰。

## 总成本，而不是只数循环层数

- 41 计数的是全部交换：每次增加正确位置，最多 n 次。
- 128 计数的是全部扩展：只从唯一的序列起点开始，各段互不重叠。
- 不能仅凭“内层操作 O(1)”就宣称总时间 O(n)，必须说明总共执行多少次。
