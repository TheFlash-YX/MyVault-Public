# 详细内容

## 93：复原 IP 地址

- `idx` 表示下一段从字符串哪个位置开始；每段只尝试从 idx 起取 1～3 个字符。
- Python 切片 `s[idx:end]` 不含 end；本段选完后递归传 end，恰是下一段的起点。固定传 idx+1 会把两位、三位段切错。
- 多位段不能以 0 开头；整数值不能超过 255。前导零或超过 255 后，继续延长当前段仍不合法，可提前结束该层的长度尝试。
- 已选四段时，仅当 `idx==len(s)` 才加入 `'.'.join(path)`；否则还有剩余字符，不能接受，也不能继续选五段。
- `'.'.join(path)` 创建新字符串，后续 path.pop 不会改变它；与把可变 path 列表直接加入结果不同。
- 首稿使用 `idx==len(s)-1`，使 `[0,0,0,0]` 选完时的 idx=4 无法保存；曾每轮只取 `s[i]` 而非连续切片，未尝试两三位段。
- 本题输入长度和段数有限，尝试长度最多三种、深度四层；记录复杂度时应说明输出字符串构造成本，不简单套用一般指数级回溯上界。

## 22：括号生成

- 递归状态为当前 path、已放左括号 left 与右括号 right。
- `left<n` 时可放左括号；`right<left` 时可放右括号，保证每个前缀都合法。
- 只判断 left>0 不够：前缀 `()` 后再放右括号会产生 `())`。
- 每层固定只有左、右两个候选，两个独立的 if 就能枚举；不需要 `for range(2*n)`。相比之下，93 要用循环枚举三种切割长度。
- 两个分支都完整执行 append、递归、pop；递归传 left+1 或 right+1，不在当前层累积修改计数。
- 长度达到 2n 时，把 `''.join(path)` 加入结果并返回。join 会生成新字符串，不需要 path[:] 或深拷贝。
- 用户首稿只在放右括号后递归，放左括号没有立即递归或撤销，导致路径和计数状态不对应。
- 合法结果数为第 n 个卡特兰数 C_n；逐个输出长度 2n 的字符串，时间与输出规模相称，递归路径 O(n) 空间，结果空间另计。
