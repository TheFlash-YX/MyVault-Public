# 概述

- **206 反转链表**是链表题的地基：迭代（三指针四步）与递归（尾插法）两版都要能手写
- **92 反转链表 II** 是 206 的「带边界版」：找前驱 p0 + 区间反转 + 两根接线接回原链
- **25 K 个一组翻转**是 92 的「循环版」：p0 逐组推进 + 四行缝合，循环边界必须是 `n >= k`
- 这套「区间反转」骨架直接复用于 25 K 个一组翻转、143 重排链表、234 回文链表

# 详细内容

## 206 迭代版：三指针四步

- 不变量：**pre 左侧已反转好，cur 及其右侧保持原样**；每圈 `cur.next = pre` 把已反转区扩一格
- 四步顺序不能乱：`nxt = cur.next`（先存桥）→ `cur.next = pre`（反转）→ `pre = cur` → `cur = nxt`
- 先改 next 再存 = 桥没搭就炸桥，**断链**；出口 cur 走到 None，pre 即新头；空间 O(1)

## 206 递归版：尾插法

- 一句话：`reverse(head)` = 先递归反转 `head.next` 之后的部分，再把 head 挂到反转后链的尾部
- **返回值 = 反转后链表的头节点**（最深层返回的 rev_head 一路原样传回最外层，每层只拿不改）
- 归程三行：`tail = head.next`（原后继 = 新链末尾）→ `tail.next = head`（head 挂尾）→ `head.next = None`（断旧链防环，**漏了末尾两节点成环**）
- ⚠️ 出口条件易写反：`if not head or not head.next: return head`——漏第二个 `not` 会变成「多节点原样返回、单节点 None 炸属性」双方向全错（实测踩过）
- 代价：O(n) 递归栈

## 92 区间反转：三步骨架

- 反转 `[left, right]` 区间，例子 `1→2→3→4→5, 2, 4 → 1→4→3→2→5`
- ① **找前驱 p0**：dummy 出发走 `left-1` 步，停在 left 前一个——接回时必须有人「拉住」左半段
- ② **区间反转**：从 `p0.next` 起跑 `right-left+1` 次 206 四步
- ③ **接两根线**：`p0.next.next = cur`（反转段旧头 → cur = right 后第一个）+ `p0.next = pre`（前驱 → 反转段新头 pre）
- **dummy 的价值**：left=1 时无真实前驱，dummy 让 p0 永远是「左段末尾」，逻辑统一免特判
- 验收 5 case：普通区间 / left=1 整链 / right=n 到尾 / 单节点 / left==right

## 25 K 个一组翻转：92 的循环版

- 先数链长 n，`while n >= k` 才翻、每翻一组 `n -= k`——**`>` 是实测踩过的 bug**：恰整除时丢最后一组（4 节点 k=2 只翻前一组），n == k 时一轮不进、整链原样返回；5 节点 k=2 的测试恰好绕开整除场景，「看着对」
- p0 不变量升级：**始终指向待处理组的前一个节点**（已处理段尾），每翻完一组推进一次；初始 dummy，头组换头免特判
- 组内 k 次 206 四步后：pre = 新头、cur = 下一组头、p0.next = 旧头 = 新尾；缝合四行**顺序即陷阱**：
  - ① `nxt = p0.next`（先存旧头，p0.next 一改就找不回）
  - ② `p0.next.next = cur`（新尾 → 下一组头，必须趁 p0.next 还指旧头时写）
  - ③ `p0.next = pre`（前段尾 → 新头）
  - ④ `p0 = nxt`（p0 推进到本组新尾）
- ②③ 颠倒：后写的 `p0.next.next` 里 p0.next 已变成 pre，实际改的是 `pre.next`，链直接断
- **组间不重置 pre 是对的**：每组第一拍 `cur.next = pre` 写下的脏指针，总会被收尾 ② 覆盖——标准模板如此
- O(n) 时间、O(1) 空间；k=2 特例即 24 两两交换（见下）；不数长度的写法：先探 k 步，不足 k 直接 return

## 24 两两交换：25 的 k=2 特例拍平版

- k=2 时跑反转循环是大材小用，拍平成**三根线**：`a = p0.next; b = a.next` 先存 → `a.next = b.next`（旧头 → 下一组）→ `b.next = a`（新头 → 旧头）→ `p0.next = b`（前组 → 新头）→ `p0 = a` 推进
- `while p0.next and p0.next.next` 天然兜住奇数长度落单，零特判
- 第一组交换就换头 → dummy 口径①；开头的空/单节点早退判断其实冗余（dummy + while 天然兜住）

## 143 重排链表：三段式缝合（206 的直接应用）

- L0→L1→…→Ln 重排成 L0→Ln→L1→Ln-1→…，拆成三道旧题：**找中点（B 条件）→ 反转后半（206 四步）→ 交错合并**
- 中点用 B 条件让 slow 停在前半段末尾、奇偶通吃；**`slow.next = None` 断开最易漏**——漏了合并接出环，调试打印死循环
- 交错合并每轮：`t1=p1.next; t2=p2.next → p1.next=p2 → p2.next=t1 → p1,p2 前进`；循环只看 `while p2`（后半 ≤ 前半，p2 空即完成，奇数时前半多出的中点天然就位）
- ⚠️ 实测踩过：`reverseList` 里 `while cur:` 忘了 `cur = head` → UnboundLocalError；阴险在**后半段只有 1 节点时提前返回救场、≥2 节点才炸**——「示例全过、提交就挂」型 bug
- 替代模式同样自洽（手写验证 5/5）：**A 条件找中点 + `reverse(mid)` 连中点一起反转**——reverse 第一步 `mid.next = None` 顺便断链，中点成两条链的**共同尾巴**，合并循环改用 `while head2.next` 在共同尾巴前停手
- 234 回文链表同款骨架：找中点 + 反转后半 + **逐对比较**（替换合并步）

## 234 回文链表：三段式的判定版

- 骨架：找中点 → 反转后半 → **p1 从 head、p2 从反转后段头出发逐对比较，不等即 False，p2 走空即 True**
- **两种模式的自洽性表**（选用一套就别混）：

| | B 条件 + `reverse(slow.next)`（推荐） | A 条件 + `reverse(mid)` |
|---|---|---|
| 中点归属 | 前半段尾巴 | 后半段的头 |
| 奇数中点参与比对？ | **不参与**——`while p2` 只走后半段长度轮 | 参与，但比的是自己 vs 自己（同节点恒等，无害） |
| 不用特判的原因 | 循环边界天然吃掉中点 | 自比恒等天然无害 |

- ⚠️ 混用即翻车：**A 条件 + `reverse(slow.next)`** 在 `[1,2]` 上后半段为空 → 比对 0 轮 → 误判 True（实际非回文）
- 断链 `mid.next = None` 在反转前做；O(n) 时间、O(1) 空间

## dummy 使用口径（链表通用）

- **①头节点会被替换/摘除、要给新头接前驱 → 用 dummy**：21/23 合并、25/92/24 反转、19/82 删节点
- **②逐步造新链 → 用 dummy 统一首节点创建**：2 两数相加、21/23 合并——免「第一个 vs 后续」特判
- **指针只读不写 → 不用**：141/142 判环、160 相交链表，起点直接 head；**头必留 → 不用**：83

## 复杂度与追问

- 两题均 O(n) 时间；迭代 O(1) 空间，递归 O(n) 栈
- 面试两版都要能写：迭代考指针功底，递归考「递到底、归时逐节点处理」的分治思维
