# 概述

- 二叉树递归题先定义返回值：它必须是父节点能继续使用的信息。
- 很多题同时存在两个量：返回给父节点的“可延展结果”，以及在当前节点更新的“完整候选答案”。

# 详细内容

## 236 最近公共祖先

- `dfs(root)` 不推荐只返回 bool；更直接的返回定义是：没找到返回 `None`，找到 `p/q` 返回该节点，已经找到 LCA 返回 LCA。
- `root == p` 或 `root == q` 时直接返回 `root`，因为当前节点本身就是有效目标信号；当一个目标是另一个目标祖先时，这个返回值也能自然给出答案。
- 左右子树递归结果都非空时，说明 `p` 和 `q` 分别落在当前节点两侧，当前 `root` 就是最近公共祖先。
- 只有一侧非空时，把非空结果继续向上返回。

## 124 二叉树最大路径和

- `dfs(root)` 返回给父节点的是“从 root 往下走的一条单边最大路径和”。
- 返回值只能是 `root`、`root -> left...` 或 `root -> right...`；不能同时带左右子树，因为路径不能分叉。
- 当前节点可以作为完整路径的拐点，用 `left_gain + root.val + right_gain` 更新全局答案。
- 返回父节点时，只能交出 `root.val + max(left_gain, right_gain)`。

## 负贡献

- `left_gain = max(left, 0)` 与 `right_gain = max(right, 0)` 表示子树如果只能提供负收益，就不接入当前路径。
- 负数节点不是不能出现在答案里；整棵树全为负时，答案应该是最大的单个负节点。
- 因此全局答案要初始化为 `-inf`，不能初始化为 `0`。

## 129 根节点到叶节点数字之和

- DFS 往下携带的不是普通路径和，而是当前已经形成的十进制数字 `cur`。
- 进入节点后更新为 `cur = cur * 10 + node.val`。
- `None` 不是一条路径的终点，返回 `0` 表示没有贡献。
- 叶子节点才是完整路径的终点，遇到叶子时返回当前完整数字 `cur`。
- 非叶子节点返回左右子树结果之和。

## 101 对称二叉树

- 递归函数比较的是两个节点是否互为镜像，而不是只比较某个节点自己的左右子树。
- 两个节点都为空返回 `True`；只有一个为空返回 `False`；值不同返回 `False`。
- 值相等后继续镜像递归：外侧对外侧，内侧对内侧，即 `left.left` 对 `right.right`，`left.right` 对 `right.left`。

## 104 最大深度

- 后序递归定义：`dfs(node)` 返回以 `node` 为根的最大深度。
- 空节点深度为 `0`。
- 非空节点深度为 `max(left_depth, right_depth) + 1`。
- 如果采用后序返回深度的写法，就不需要额外传入 `depth` 参数；传参版属于前序携带当前深度、到叶子更新答案的另一种口径。

## 110 平衡二叉树

- 每个节点都要满足左右子树高度差不超过 1，不能只检查根节点。
- 推荐让 `height(node)` 返回高度，并用 `-1` 作为“不平衡”哨兵。
- 左右子树任一返回 `-1`，当前节点也直接返回 `-1`。
- 当前节点左右高度差超过 1 时返回 `-1`；否则返回 `max(left, right) + 1`。
- 这种写法把“高度”和“是否平衡”合在一个后序返回值里，每个节点只访问一次。

## 543 二叉树直径

- `dfs(node)` 返回从当前节点向下的最长边数，也就是 `max(left, right) + 1` 的节点高度口径。
- 经过当前节点的直径是 `left + right`；它可以在任意节点出现，因此用全局答案取最大值，不能直接覆盖成 `left + right`。
- 返回给父节点时只能选择一侧，不能把左右路径同时返回，否则路径会在当前节点分叉。

## 113/112 路径和

- 路径和题要明确终点是叶子节点：`None` 不是一条路径的结束位置。
- 113 需要携带 `path` 并回溯：进入节点追加，尝试完左右分支后 `pop`；加入答案时使用 `path[:]` 保存当时的快照。
- 113 在叶子节点判断剩余目标和是否为 0，满足时保存路径；非叶子节点再继续递归。
- 112 只判断是否存在一条路径，不需要保存路径；到叶子时返回 `target == 0`，左右子树结果用 `or` 合并。

## 226 翻转二叉树

- 每个节点的局部操作是交换左右孩子：`node.left, node.right = node.right, node.left`。
- 因为交换只依赖当前节点，前序、后序和层序都可以；递归版本的关键是对整棵树执行这项局部变换。
- 只做原地修改的 DFS 辅助函数可标注为 `-> None`；整体时间复杂度 `O(n)`，递归栈空间 `O(h)`。
