# 详细内容

## 稀疏注意力：按规则构造候选并加权

- 全局位置能查看所有位置；普通位置的候选为全局位置与局部窗口 `|i-j|<=W` 的并集。
- 使用集合去重，避免一个位置因同时属于全局和窗口而重复占用 Top-T 名额、重复贡献输出。
- 计算 `score=Q[i]·K[j]`，只保留 score>0 的候选。
- 排序键为 `(-score,j)`，分数降序、编号升序，再取前 T 个。
- 对每个保留位置按维度累加 `output[d]+=score*V[j][d]`；K 用于得分，V 用于输出，不能读错矩阵。
- 本题规则直接使用原始正分加权，没有 softmax 或归一化步骤；没有正分候选时返回零向量。
- 参考方法 `sparseAttention(Q,K,V,globalPositions,W,T)` 的全局位置采用 0 起始下标，材料中位置 2 对应传入 `[1]`。
- 每个位置最多 C 个候选时，时间为 `O(L*(C*D+C log C))`；不计返回矩阵，辅助空间 O(C+D)，结果空间 O(LD)。

## 连续分段：枚举最后一段

- 数组保持原顺序，恰好划分成 k 个连续非空段，最小化所有段和中的最大值。
- `dp[parts][i]` 表示前 i 个元素分成 parts 段的最小最大段和。
- 切点 j 表示前 parts-1 段共用了 j 个元素，最后一段为 Python 切片 `nums[j:i]`。
- 前缀和使最后一段之和等于 `prefix[i]-prefix[j]`。
- 固定切点时取 `max(dp[parts-1][j], prefix[i]-prefix[j])`，因为最慢的一段决定本次划分的最大值；枚举不同切点再取 min，选择最优划分。
- 合法范围为 `parts-1<=j<i` 且 i>=parts，保证每段非空。
- 初始化 `dp[1][i]=prefix[i]`，其他状态先设无穷大；最终返回 `dp[k][n]`，假设 `1<=k<=n`。
- `[3,5,2,7,4]` 分两段，可切为 `[3,5,2] | [7,4]`，段和为 10 和 11，答案 11。
- 时间 O(k*n²)，空间 O(k*n)。原材料缺少数据规模，不能仅凭样例通过保证符合原笔试时间限制。
