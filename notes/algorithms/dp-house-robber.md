# 概述

- 198/213：「选或不选」型 DP 的母版（股票系列、337 树上打劫都是它的变种）
- 环形版的核心技巧：**分类破环**——把环上多出的约束拆成两种情况，各砍掉一个元素变直线子问题

# 详细内容

## 状态与转移（198 直线版）

- `dp[i]` = **考虑**下标 0..i 能偷到的最大金额（不要求真偷第 i 间——注意与「以 i 结尾」型口径的对照，见相关链接）
- 转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`——不偷第 i 间 / 偷第 i 间（偷了必须隔一间）
- 滚动变量：`dp0`（dp[i-2]）、`dp1`（dp[i-1]），一行元组赋值 `dp0, dp1 = dp1, max(dp1, dp0 + x)`，右侧表达式先用旧值求值，天然无串扰
- 初始化 `dp0 = dp1 = 0`：`dp[0] = nums[0]`、`dp[1] = max(nums[0], nums[1])` 被循环自动推出，免写 base case，长度 1/2 边界自动覆盖
- 走一遍 `[2,7,9,3,1]`：`(0,2)→(2,7)→(7,11)→(11,11)→(11,12)`，答案 12
- 手写显式状态时要正确覆盖长度 1/2：`dp0`、`dp1` 分别代表前两间和前一间的最优值；不要让 `i == 1` 时的 `dp[i-2]` 依赖 Python 负下标的偶然结果。
- 如果希望支持空数组，要先单独返回 `0`；题目保证非空时也可以省略，但边界语义要清楚。

## 环形版（213）：分类破环

- 环比直线只多一条约束：第 0 间与第 n-1 间不能同偷 → 任何合法方案必满足以下至少其一：
  - 方案 A：不偷第 0 间 → 直线子问题 `nums[1:]`
  - 方案 B：不偷第 n-1 间 → 直线子问题 `nums[:-1]`
- **环形答案 = max(rob(nums[1:]), rob(nums[:-1]))**：两个子解都天然不违反环形约束（各自少偷一间端点），最优解必落其一，取 max 完备
- 边界：`len == 1` 时两刀都切成空数组（rob 返回 0，把唯一一间切丢），需单独返回 `nums[0]`
- 切片语义：`nums[1:]` 去掉第 0 个、`nums[:-1]` 去掉最后一个；切片越界不报错、只取到空列表
- 两次切片本身会复制数组，213 的滚动 DP 因此会产生 `O(n)` 额外空间；若要严格保持 `O(1)`，可以让线性辅助函数接收左右边界，用下标遍历原数组。

## 延伸

- 337 打家劫舍 III（房子排成二叉树）：每节点后序返回 `(偷它, 不偷它)` 二元组
- 破环套路通用：环形约束 → 分类讨论 → 砍元素变直线 → 取 max/min（石子合并环形版、环形加油站同理）
