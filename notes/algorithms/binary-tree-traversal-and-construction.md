# 概述

- 中序遍历的访问顺序是左子树、当前节点、右子树。
- 前序与中序构造二叉树的核心是：前序负责拿根，中序负责切左右，左子树大小负责切前序区间。
- BST 验证不能只看直接左右孩子；要么用中序严格递增性质，要么用祖先传下来的上下界约束。

# 详细内容

## 94 中序遍历

- 递归版：递归左子树，访问当前节点，递归右子树。
- 递归辅助函数可以不返回值；它的职责是把当前子树的中序结果追加到外部结果数组。
- 迭代版的核心流程：一路向左压栈；走到空后弹栈访问；再转向右子树。
- 外层循环条件必须是 `while node or stack`，因为转向右子树后，即使栈暂时为空，也还需要继续处理新的 `node`。
- 栈中保存的是“左侧还没处理完、自己也还没访问”的祖先节点。

## 98 验证二叉搜索树

- BST 的约束是“左子树所有节点小于当前节点，右子树所有节点大于当前节点”，不是只检查 `root.left.val < root.val < root.right.val`。
- 上下界递归定义：`dfs(node, low, high)` 表示当前节点必须满足 `low < node.val < high`。
- 进入左子树时，上界更新为当前节点值：`dfs(node.left, low, node.val)`。
- 进入右子树时，下界更新为当前节点值：`dfs(node.right, node.val, high)`。
- 递归结果必须向上传递；只调用左右递归但不 `return` 合并结果，会把子树里的非法状态吞掉。
- 中序迭代版利用 BST 中序严格递增；边遍历边记录前一个访问值 `pre`，若 `node.val <= pre` 立即返回 `False`。

## 144 前序遍历

- 前序遍历顺序是当前节点、左子树、右子树。
- 递归版先收集当前节点值，再递归左、右子树。
- 迭代栈版是弹出谁就访问谁；为了让左孩子先被弹出，入栈时要先压右孩子，再压左孩子。
- 前序迭代比中序迭代更直接，不需要一路压左链，根节点入栈后循环弹栈即可。

## 105 前序与中序构造二叉树

- 前序遍历的第一个元素是当前子树根节点。
- 在中序遍历中，根节点左边是左子树，右边是右子树。
- 预处理 `in_map = {val: i for i, val in enumerate(inorder)}`，把找根下标从每次 `O(n)` 降为 `O(1)`。
- LeetCode 105 默认节点值不重复，所以值到下标的哈希表是合法的；若有重复值，仅靠前序和中序通常无法唯一还原。
- 推荐传左闭右开下标区间，避免频繁切片复制数组。

## 四个区间变量

- `pre_l`：当前子树在 `preorder` 中的起点，也是当前根的位置。
- `pre_r`：当前子树在 `preorder` 中的右边界，不包含。
- `in_l`：当前子树在 `inorder` 中的起点。
- `in_r`：当前子树在 `inorder` 中的右边界，不包含。
- 空区间条件是 `pre_l == pre_r`，表示当前子树不存在。

## 区间切分

- `idx = in_map[root_val]` 找到根在中序中的位置。
- `left_size = idx - in_l` 得到左子树节点数量。
- 左子树前序区间是 `[pre_l + 1, pre_l + 1 + left_size)`，中序区间是 `[in_l, idx)`。
- 右子树前序区间是 `[pre_l + 1 + left_size, pre_r)`，中序区间是 `[idx + 1, in_r)`。
