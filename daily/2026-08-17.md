# 今日学习

- 718 最长重复子数组三连问自评：「子数组必须连续、子序列可以不连续」自己说对了（整题的钥匙）；但 dp 定义又答成「考虑到为止」口径、答案又取 dp[m][n]——「以 i 结尾」口径两天内第二次答错
- 718 补课：`dp[i][j]` 以 i-1、j-1 **结尾**；不等直接 0——LCS 的 `max(dp[i-1][j], dp[i][j-1])` 本质是「跳过一个元素」，连续结构不允许跳；答案全表扫（`[3,2,1]` 结束在 dp[3][3]=3 而 dp[5][5]=0，取末格会得 0）
- 亲手写 718 一次通过（else: dp[i][j]=0 冗余但无害）；弄懂灵神版 `max(map(max, f))` 一行流（map 逐行求行最大、外层 max 取全表）与 enumerate +1 错位 padding 技巧
- ⚠️ 命名教训：自己写的函数叫 `findlength`（小写 l），LeetCode 调 `findLength`——文件里两个函数并存时评测跑的是参考版，自己的代码根本没被执行
- 227 基本计算器 II 三连问全忘 → 补课核心分野：「`+ -` 能拖（数字带符号压栈，最后 sum）、`* /` 不能拖（数字读完立刻与栈顶融合）」就是全部考点
- prev_op='+' 哨兵 = 假装开头有 `"0+"`（加法单位元），与 198 的 0/0、152 的 1/1 同族——单位元初始化免 base case 已成型为可迁移套路
- Python `//` 向下取整 vs 题目向零取整：`-3//2=-2` 但要 -1；负数来自 `-num` 压栈技巧（`14-3/2` 手推踩坑：应得 13，`//` 错成 12）；解法 `int(a/b)`
- 表达式三写法：中缀/前缀（波兰）/后缀（逆波兰 RPN）；227 的栈 = 简化版调度场算法；计算器家族阶梯 150 < 227 < 224 < 772
- 亲手写 227 一次通过（`int(stack.pop()/num)` 的坑避开了）；小瑕疵：参数名 nums、类型标注 list[int]，实际是字符串 s
