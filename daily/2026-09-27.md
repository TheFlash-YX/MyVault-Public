# 疑问卡点

- 排列下一层要重新扫描所有下标；组合/子集下一层只从 `i+1` 往后选。
- 47 用 `not used[i-1]` 标识同层重复；90 用 `i>index` 标识同层重复，两题都允许同一路径使用不同下标的相同值。
- 93 的 `s[idx:end]` 不包含 end，所以 end 是下一段的起点；`".".join(path)` 已生成新字符串，不需深拷贝路径。
- 22 只判断左括号数量大于 0 不够，放右括号需满足 `right<left`。
- 31 的 `nums[index+1::-1]` 会向左取前缀；反转后缀应从 `index+1` 向右取再反转。
