# 今日学习

- 207 课程表三问自评：点/边方向、无环等价、Kahn「摘入度 0 的点」思路全对；但「环为什么致命」当时说不出 why
- 207 亲手写**三色 DFS** 判环，踩致命 bug：`if y==1 or y==0 and dfs(y)` 拿**邻居编号 y** 和颜色比，而不是 `colors[y]`——最简用例 `[[1,0]]`（应 True）直接误报 False，三个用例错两个；修复：`colors[y]==1`（灰=回边=环）→ `colors[y]==0 and dfs(y)`（白=递归），黑自动跳过
- 207 补课：环 = 循环论证/死锁（`[[1,0],[0,1]]` 里没有任何一门课能先学）；Kahn（入度 0 入队、摘点减后继入度、摘完 n 个无环）与三色 DFS 等价；复杂度 O(V+E)
- 快排三问自评：分治方向答对（先分后治）；挖坑法思路对；递归出口忘了（`l>=r`）、最坏 O(n²) 答对
- 快排补课：分治三件套（分=partition 主力、治=递归、合=无）；归并「先治后合」vs 快排「先分后治」；挖坑法（坑接力、`>=`/`<=` 防死循环）vs 双向交换法（严格 `<`/`>`、交换后强制推进）
- 双向交换法精髓：**全相等数组——挖坑法 pivot 归端→O(n²)、交换法 pivot 归中→O(n log n)**（实验：8 个 3 归位下标 4 vs 0）；结束与 `nums[j]` 交换而非 `nums[i]` 的三个理由（i 越界 / `nums[i]>pivot` 破坏划分 / j 自交换无害）
- 亲手写 `912.SortArray.py` 一次通过：双向交换 partition + ordered 剪枝；7 个 edge case（乱序/全相等/升序/降序/空/单元素/负数）全过
- 收获：partition 返回值可复用 Quickselect（TOP K，平均 O(n)）；手撕快排面试要说清自己那版在全相等数组上的行为
