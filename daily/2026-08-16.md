# 今日学习

- 169 多数元素动手写代码：首版把「换候选」与「计数增减」两个决策揉成 `if count==0 and candidate==x` → count 一路变负、candidate 永不更新，`[2,2,1,1,1]` 返回 2；拆成两个独立 if 后与三元表达式版逻辑完全等价
- Python 三元表达式 `A if 条件 else B` 是**表达式**（整体取一个值），`count += 1 if x == candidate else -1` 等价于 if/else 两段式；else 后跟值不跟语句
- 198 打家劫舍三问全对：`dp[i] = max(dp[i-1], dp[i-2]+nums[i])`；滚动变量一行元组赋值；初始化 0/0 免 base case
- 213 环形打家劫舍现场没推出来，补课「分类破环」：`max(rob(nums[1:]), rob(nums[:-1]))`，len==1 兜底；顺带弄清切片 `nums[1:]` / `nums[:-1]` 语义（负下标、越界不报错）
- 53 最大子数组和遗忘后复习：Kadane，`dp[i] = max(dp[i-1]+nums[i], nums[i])`（自己的旧代码本来是对的）；关键口径——「以 i 结尾」→ 答案全表扫，区别于 198 的「考虑到 i 为止」→ 答案取 dp[n-1]
- 152 乘积最大子数组：状态设计对但递推缺交叉项（只写 `max(dp0*x, x)` 在 `[-2,3,-4]` 返回 -4）；补上交叉项 + temp 保旧值后正确，升级为元组赋值一行版 + 初始化 1/1（空乘积）；0 靠重启项自然处理，无需 if
