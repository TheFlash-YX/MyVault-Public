# 今日学习

- 克隆 JavaGuide 仓库到本地，确定学习路线：**零基础 + 求职面试 + 面试题驱动**——先用基础面试题打地基（1~2 周），再啃集合/并发/JVM 等源码类硬核题。
- 安装 OpenJDK 21.0.12（`brew install openjdk@21`），在 `~/.zshrc` 配置 `JAVA_HOME` 与 PATH；跑通第一个 Hello World（javac 编译 → .class 字节码 → java 运行），并用 `javap -c` 反编译亲眼看到字节码指令。
- **第 1 讲 JDK/JRE/JVM**：JDK ⊃ JRE ⊃ JVM；跨平台 = 字节码 + 各平台 JVM 屏蔽系统差异。
- **第 2 讲 编译型 vs 解释型**：Java 是"先编译后解释"混合模式；JIT 把热点代码编译成本地机器码，启动慢但长期性能逼近 C。
- **第 3 讲 8 种基本类型**：byte/short/int/long（1/2/4/8 字节）+ float/double + char（可存中文）+ boolean（不能用 0/1）。验证两大坑：`0.1+0.2=0.30000000000000004`（金额必须用 BigDecimal）、`Integer.MAX_VALUE+1=-2147483648`（溢出不报错）。
- **第 4 讲 装箱拆箱**：`Integer a = 127` 实为 `Integer.valueOf(127)`（javap 证实）；Integer 缓存 -128~127，故 127 的 `==` 为 true、128 为 false；`Integer == int` 触发拆箱比值；`new Integer()` 绕过缓存且 Java 9+ 已废弃。
- **第 5 讲 String**：常量池共享字面量；不可变（`concat` 不接收返回值等于白调）；`new String("abc")` 创建 1~2 个对象；`intern()` 取池中对象。
- **答疑 堆 vs 栈**：现场把两块内存各自塞爆——栈（无终止递归压 47387 层 → StackOverflowError）、堆（`-Xmx10m` 下第 7 个 1MB 对象 → OutOfMemoryError）；引用是"遥控器"（栈存地址、堆存本体）；字符串常量池在堆里。
