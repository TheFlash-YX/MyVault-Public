# 今日学习

- 198 打家劫舍：`dp[i]` 表示考虑下标 `0~i` 的最大金额，不要求一定偷第 `i` 间；转移为 `max(dp[i-1], dp[i-2] + nums[i])`。
- 198 空间压缩：用两个变量保存前两个状态即可做到 `O(1)` 空间；显式初始化时要覆盖长度 1/2，不能依赖 `dp[-1]` 的偶然行为。
- 213 打家劫舍 II：环形约束通过分类拆成两个线性问题，分别处理 `0~n-2` 和 `1~n-1`，取两者最大值；长度 1/2 需要单独处理。
- 718 最长重复子数组：`dp[i][j]` 表示以 `nums1[i-1]`、`nums2[j-1]` 结尾的最长公共子数组长度；相等时从左上角延伸，不等时清零，答案取全表最大值。
- 718 索引修正：使用 `(n+1)×(m+1)` 的 padding 表时，结果写入 `dp[i+1][j+1]`，从 `dp[i][j]` 转移，避免使用负下标。

# 疑问卡点

- 198 的“考虑到 i 为止”和 718 的“以 i、j 结尾”不能混用；前者可以沿用上一个状态，后者不相等时必须清零。
- Python 负下标虽然合法，但不应替代 DP 中明确的边界状态。

# 感想收获
