# 今日学习

- 142 环形链表 II 自评全对：相遇后 fast 回 head 双指针同速走，再次相遇即入口；推导 slow=a+b、fast=a+b+n(b+c)、fast=2×slow → **a=(n-1)(b+c)+c**（读法：a = (n-1) 整圈 + c，所以两指针走 a 步都落在入口）
- 143 重排链表思路全忘 → 重学三段式缝合：**找中点（B 条件）→ 反转后半（206 四步）→ 交错合并（`while p2`）**；`slow.next=None` 断开最易漏（漏了合并接出环、打印死循环）
- 143 手写代码踩「示例全过、提交就挂」型 bug：`reverseList` 里 `while cur:` 漏写 `cur = head` → UnboundLocalError；后半段 1 节点时提前返回救场（[1,2,3,4] 过）、≥2 节点才炸（[1,2,3,4,5] 崩）
- 找中点 A/B 条件辨析（今日最值）：A=`while fast and fast.next`、B=`while fast.next and fast.next.next`；**奇数链两版一致，偶数链 A 让 slow 多走一格**（fast 最后一跳「走 1 步到尾、走 2 步掉 None」，A 放行 B 拦下）；口诀「判环用 A、切半用 B」
- A 条件真翻车场景：234 回文 `[1,2]` 用 A → 后半段空、比对 0 次 → 误判 True；143 用 A 是侥幸（合并只要求后半 ≤ 前半）
- 对齐实际进度：25/23/21/141 已在其他会话做完（merge 笔记 08-25 已建）
- **Java 第 10 讲 equals/hashCode/==（Object 三件套）**：== 基本类型比值/引用类型比地址；equals 默认实现就是 ==（不重写等于白搭），String 重写逐字符比；hashCode 给 HashMap/HashSet 分桶——先定桶再桶内 equals。契约：equals 相等 → hashCode 必须相等；hashCode 相等 ⇏ equals 相等（哈希冲突）
- 本讲最值：只重写 equals 不重写 hashCode → 两对象落不同桶、equals 根本没机会被调用 → put 进 get 出 null、HashSet 出逻辑重复。操作手册：**equals 比哪些字段，hashCode 就用哪些字段**（`Objects.hash(id)`）
- equals 五规范：自反（x.equals(x) 必 true，集合查重保命前提）、对称（用 getClass 而非 instanceof，Timestamp/Date 翻车案例）、传递、一致、非空；重写五步走：this==o 短路 → null 检查 → getClass → 强转 → 比字段
- String.hashCode 乘 31：奇质数分布均匀 + `(i<<5)-i` 位移优化；equals/hashCode 字段要加 final（参与哈希后再变 → 对象丢在自己的 Set 里）；String 不可变所以是绝佳 key
- 补讲回顾：Integer 缓存 -128~127（127 == 为 true、128 为 false、一边基本类型触发拆箱变比值）；final 口诀「final 类断子绝孙，final 方法不许重写，final 变量只赋一次」
- 手写练习 Student(id,name) 按 id 去重：equals 五步走 + hashCode 全对；`size()=2`、id 同 name 不同 equals 为 true、只写 equals 时 size 变 3
