# 今日学习

- **第 9 讲 接口 vs 抽象类**：一句话本质——抽象类 is-a（身份/模板）、接口 can-do（能力/契约）。8 点区别：①extends 单继承 vs implements 多实现 ②有无构造方法 ③任意字段 vs 默认 public static final 常量 ④抽象+普通方法 vs Java 8 前只能抽象 ⑤方法修饰符 ⑥Java 8 default/static 方法体 ⑦Java 9 private 方法 ⑧设计语义。default 方法为向后兼容而生（给 Collection 加 stream() 不破坏老实现）；diamond 冲突——两类同名 default 必须重写、用 `接口名.super.方法()` 选一个，这也解释了接口字段为何必须 final。决策：公共代码/模板用抽象类，跨类层次能力契约用接口，Java 8 后倾向面向接口编程。类比：抽象类=亲爹（单继承），接口=技能证书（多实现）。
