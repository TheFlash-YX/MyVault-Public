# 疑问卡点

- n-2 只对应第 2 大；target 是固定目标下标，pivot 才是划分时比较的值。
- continue 不会自动移动指针；交换与推进必须在循环体内。
- 原随机下标 index 不代表基准最终位置，结束后需交换 nums[left] 和 nums[r] 并返回 r。
- 不要每轮划分整个数组，或把 target 直接当作新的区间边界；应维护 left、right，按返回下标缩小一侧。
- 重复值配合非严格扫描容易把基准放端点；严格扫描加交换推进可以避免全相等时的这种退化。

# 感想收获

- partition 的不变量、推进方式、结束交换与返回位置必须成套使用。
- 快速选择复用快排划分，但只处理一侧，不需要把整个数组排序。
